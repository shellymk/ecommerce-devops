# Roteiro para o relatório da Atividade 1

Material para preencher após a execução real. Não é um relatório final pronto para envio.
Manter identificação acadêmica somente na versão privada entregue no AVA.

## Objetivo e contextualização

Explicar como a Loja de Estudos aplica colaboração, responsabilidade compartilhada,
Lean, Agile e automação. Descrever o escopo simulado e o uso de dados fictícios.

## Prática 1

Apresentar projeto, backlog, papéis efetivamente exercidos, estrutura e dependências.
Justificar Trunk-based Development. Incluir URL do repositório, branch da funcionalidade,
commits padronizados, PR, revisão realizada e evidência do merge, quando concluído.

## Prática 2

Explicar Build → Testes → Artefato, jobs, steps, `needs` e Fail Fast.
Apresentar lint, testes unitários, integração HTTP e cobertura medida.
Incluir URL do run, commit validado, versão do wheel, download e teste do pacote.

## Evidências a coletar

| Evidência | Registro real a inserir |
|---|---|
| Loja funcionando | Captura do catálogo e pedido simulado. |
| Repositório | URL e captura da estrutura. |
| Branches e commits | Histórico real e nomes das branches. |
| Pull Request | URL, diff, revisão e situação do merge. |
| CI | URL do run e sequência dos jobs. |
| Testes | Quantidade aprovada e relatório da execução. |
| Cobertura | Percentual medido e relatório HTML/XML. |
| Artefato | Nome versionado, link e validação da instalação. |

## Resultados e conclusão

Descrever somente resultados comprovados, dificuldades encontradas e correções.
Relacionar as etapas realizadas aos conceitos DevOps. Não afirmar execução de Docker,
infraestrutura, observabilidade, segurança completa ou deploy nesta entrega inicial.
