## Entrega atual das Práticas 1 e 2

| Prática | Exigências |
|---|---|
| 1 | E-commerce; nome, descrição, objetivos, funcionalidades, responsabilidades e backlog; estrutura src, tests e docs; README e dependências; Gitflow ou Trunk-based com justificativa; funcionalidade em branch própria e PR; Conventional Commits; URL, histórico e documentação Git. |
| 2 | YAML; dependências automáticas; Build → Test → Artifact; testes unitários e integração; validação e relatório de cobertura; lint; interrupção quando falhar; artefato identificado por versão; evidências reais e documentação da esteira. |

O limiar de cobertura de 90%, FastAPI, Ruff, pytest e GitHub Actions são escolhas
deste projeto. O roteiro não impõe essas ferramentas específicas nem esse percentual.
O GitHub Actions expressa a ordem dos estágios por dependências `needs` entre jobs.
